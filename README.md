Password Strength Checker

Project Overview

A Python-based application that evaluates password strength based on five security criteria.

Objective

To analyze password strength and provide feedback for improving password security.

Features

- Minimum password length validation
- Uppercase letter detection
- Lowercase letter detection
- Numeric digit detection
- Special character detection
- Strength classification
- Improvement suggestions
- Automated demo test cases
- Interactive command-line menu

Technologies Used

- Python
- Built-in string module

Password Strength Criteria

1. Minimum 8 characters
2. At least one uppercase letter
3. At least one lowercase letter
4. At least one numeric digit
5. At least one special character

Strength Classification

- Weak: 0–1 criteria satisfied
- Moderate: 2–3 criteria satisfied
- Strong: 4 criteria satisfied
- Very Strong: 5 criteria satisfied

How to Run

python password_strength_checker.py
